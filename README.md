# WordBlock website

The landing page and the privacy policy Google Play requires, as plain HTML, in English and
简体中文 (the switch is top right).

- `index.html`: the landing page
- `privacy.html`: the privacy policy
- `style.css`, `img/`: everything else. The images come from the app repo's `store/` folder.

No build step. Open `index.html` in a browser to preview, or publish with GitHub Pages
(Settings → Pages → Deploy from a branch → main → / (root)). The privacy policy is then at
`https://<github-user>.github.io/wordblock-site/privacy.html`.
